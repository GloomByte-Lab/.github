## Contributing

Bug reports, documentation fixes, design feedback, and code contributions are
welcome. Start with the contribution guide in the repository you want to help
with. Larger changes should begin with an issue or discussion so maintainers
and contributors can agree on scope before implementation starts.

Please report security vulnerabilities privately through the affected
repository's Security tab.
