# Security policy

## Report a vulnerability

Do not open a public issue for a suspected vulnerability.

Open the affected repository, select **Security**, then select **Report a
vulnerability**. Include:

- the affected version, commit, or deployment;
- clear reproduction steps or a proof of concept;
- the impact you observed or expect;
- any conditions needed for exploitation;
- a suggested fix, if you have one.

Remove credentials, personal data, and unrelated sensitive information from
the report. GloomByte Labs will acknowledge the report, investigate it, and
coordinate disclosure with the reporter. Please allow a reasonable remediation
period before publishing details.

If private vulnerability reporting is unavailable, contact a maintainer
privately and ask for a secure reporting channel. Do not include vulnerability
details in that first message.

## Supported versions

Each project documents supported releases in its repository. Unless a project
says otherwise, only the latest release receives security fixes.
